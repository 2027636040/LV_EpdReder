# Wi-Fi 接入技术储备

## 当前状态

平台已有统一网络选择和通知接口，实际业务当前使用蓝牙个人局域网（PAN）共享网络。Wi-Fi 的网卡登记位置和设置入口已经预留，但没有接入实际 Wi-Fi 设备、扫描连接及配网流程；[设置页](../../src/ui/apps/app_settings.c)仍显示“未接入 WiFi 设备”。

[network.h](../../src/services/net/network.h)定义 `NETWORK_AUTO`、`NETWORK_PAN`、`NETWORK_WIFI` 及 `network_snapshot_t`。快照包含是否就绪、来源、IPv4 地址和网络代次 `generation`。代次表示当前连接条件已经变化，供请求判断自己是否仍属于有效网络。

## 已实现的选择与通知

[network.c](../../src/services/net/network.c)在 lwIP 的 TCP/IP 线程采样网卡，只有接口启用、链路有效、IP 和网关非零时才选为就绪网络。自动模式先检查 Wi-Fi，再检查 PAN；显式选择某来源时只检查该来源，不自动转向另一个来源。

当前 PAN 登记为 `b0`，Wi-Fi 名称为空。`network_register_interface()` 接收 SDK 两字符网卡名，并触发重新采样；适配器不能把 lwIP 另行编号的显示名称直接当成该参数。服务根据已选网卡更新默认路由，保存并切换相应 DNS；静态地址或驱动需要显式补充 DNS 时使用 `network_set_dns()`。

应用订阅 RT-Thread 事件并在自己的线程读取快照，网络线程不回调可卸载应用的业务函数。`network_unsubscribe()` 返回后才可销毁对应事件对象。天气、校时和公共 HTTP 已采用网络状态及代次，Wi-Fi 接入后应继续复用这些接口。

## 待实施职责

| 部分 | 待完成内容 |
| --- | --- |
| 硬件与驱动 | 确定实际模块、总线、供电、复位和中断，完成 SDK 驱动及 lwIP 网卡接入。芯片型号和总线尚未选定。 |
| 平台适配 | 登记真实网卡名，传递链路、地址、DNS 及移除事件；停用设备时使对应网络失效。 |
| 连接服务 | 持有扫描、认证、连接、断开和重连状态，串行处理用户请求，不让页面直接控制总线。 |
| 配网页面 | 展示扫描结果、输入和保存网络配置，区分密码错误、未取得地址及可用网络；离开页面时取消页面专用任务。 |
| 配置存储 | 保存确认后的网络参数，定义覆盖、删除及凭据保护；不能将系统设置中的启用选项等同于完整网络配置。 |

拟定连接过程为“关闭 → 启动设备 → 扫描/选择 → 认证连接 → 获取地址及 DNS → 网络就绪”。链路已连接但尚无地址时不发布 `ready`。用户取消、关闭或设备移除需要使旧扫描和连接结果失效，再关闭传输和释放对象。

业务请求只依赖统一网络快照。切换来源、地址或连接代次后，旧请求取消并由各业务决定是否重试；不将已经建立的 TCP/TLS 会话迁移到新网卡。公共 HTTPS 对套接字及 TLS 可取消，SDK 同步 DNS 仍有返回后才能检查取消的边界。

Wi-Fi 连接服务拥有网络凭据和驱动句柄，应用只获得可用网络。UI 持有结果副本，不借用扫描工作缓冲。网络密码不放在应用清单、普通日志或文档样例中。凭据持久化位置及保护方式在驱动和连接服务设计时确定，当前不声明已经实现加密保存。

## 与其他储备的关系

天气和微信读书使用现有公共 HTTP，可在网卡接入后验证切换行为；语音使用未来的双向 WSS，切换时结束原录音任务。Wi-Fi 与 PAN 的待机、关闭和唤醒属于 [PM 接入](PM_INTEGRATION.md)的外设编排，需要真实驱动支持后再测量。

## 验证入口

现有接口核查入口是网络服务源码和[公共 HTTP 测试](../../modules/common/http/tests/run_http_tests.py)。未来网卡适配需要增加驱动与状态转换验证，覆盖认证成功但未取得地址、DNS 更新、断线重连、来源选择、关闭及移除。

设备验收应让天气、校时和微信读书共同订阅网络，在 Wi-Fi/PAN 切换过程中确认旧请求退出、订阅对象正确释放及新请求使用正确路由。当前没有 Wi-Fi 专用构建参数、配网运行结果或吞吐/功耗结论。
