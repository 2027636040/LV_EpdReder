# 应用能力演进储备

## 已落地能力

应用设计说明当前实现，技术储备保留后续仍可复用的机制及候选业务。以下已有能力不再作为从零实施的目标。

| 主题 | 当前落点 | 延续的设计原则 |
| --- | --- | --- |
| 本地多格式阅读 | [书架设计](../../modules/books/DESIGN.md)、[格式说明](../../modules/books/formats/README.md) | TXT 保留源字节位置；Markdown、EPUB、MOBI 转换为与字号无关的记录；重新排版按内容位置恢复。 |
| EPUB 与 MOBI 资源 | [公共阅读器](../../modules/common/reader/reader.h)、[MOBI 私有库](../../modules/books/codecs/mobi/README.md) | 文件解析在工作线程，字体度量及控件在 UI；私有库按需装载，取消后等待使用者退出。 |
| 图片解码 | [图库设计](../../modules/gallery/DESIGN.md)、[公共图片组件](../../modules/common/image/raster.h) | 软件路径流式处理，硬件按真实工作区申请；显示和缓存持有的图像引用分别释放。 |
| 跨应用文件打开 | [内容打开契约](../CONTENT_HANDLERS.md) | 按已安装应用声明发现处理者，由框架交接完整路径；书架和图库已接入，应用复制路径并在延后打开时复查存储会话。 |
| 看板参考应用与预览 | [看板设计](../../modules/board/DESIGN.md) | 配置驱动卡片，按平台摘要变化更新；设备和主机预览复用布局代码，设备集成与显示仍需验证。 |
| 统一词库与学习 | [单词设计](../../modules/words/DESIGN.md)、[WDB2](../../modules/words/WDB2.md) | 电脑端生成完整索引，设备按需读取；永久学习身份独立于词条序号、词库顺序和范围。 |
| 微信读书 | [微信读书设计](../../modules/weread/DESIGN.md) | 账号协议留在独立应用，传输及阅读按源码组件复用；缓存和进度按账号及内容身份隔离。 |
| 公共 HTTPS | [epd_http.h](../../modules/common/http/epd_http.h) | GET/POST、证书和域名校验、网络代次、取消、完整响应及 gzip 已共用；业务处理仍由应用负责。 |

共享阅读组件目前仍从 `books/document` 和 `books/formats` 编译部分实现；共享图片组件的供应商源码已位于 `modules/common/image/third_party`。公开组件边界已经存在，后续物理目录整理和独立交付状态由[平台路线图](../PLATFORM_ROADMAP.md)维护。

## 阅读与内容储备

本地阅读继续维护 TXT、Markdown、EPUB、MOBI 及当前兼容族，PDF、DOC、DOCX、FB2 等扩展已取消。早期方案中的固定版式渲染、Office 转换及其解码库不再作为当前实施任务。

EPUB 的有效储备是稳定内容身份、阅读顺序与目录分离、受限样式、资源相对路径和转换缓存。MOBI 的有效储备是按记录/章节处理、延迟资源读取和解码库生命周期。复杂样式或异常文件的新增支持必须落到实际解析器及验证样本，不能因为容器可打开就宣布完整格式兼容。

阅读性能和缓存的当前实现及验证边界由[阅读性能方案](../READER_PERFORMANCE_PLAN.md)维护。[跨应用内容打开](../CONTENT_HANDLERS.md)已实现普通文件的处理者发现和交接，书架与图库已接入；摘录与查词的文本、词条传递仍待定义。[看板参考应用及预览](../../modules/board/DESIGN.md)已有实现，后续平台阶段安排见[平台路线图](../PLATFORM_ROADMAP.md)。

## 单词与微信读书储备

单词应用采用一套 WDB2 词库和多个学习范围。完整词库约 204.08 MiB，标准包安装到 TF 卡；内部安装仅适用于实际能够放入内部存储的资源组合。原来的多词书文件选择和逐本导入已被替代，旧格式兼容用于保留学习记录，不作为新的内容组织方式。

词库生成可保留来源、去重和拒绝记录，发布资源需要对应的来源说明。资源合并不会改变原始数据的授权范围。下一阶段效果评估应围绕实际词条覆盖、稳定身份和复习恢复，不重新引入文件名作为用户学习范围。

微信读书的协议、公共 HTTP、账号隔离缓存及共享阅读已经接入。已有设备结果只覆盖双重验证登录和书架；v3 目录/阅读页导航修复已经编译，板上完整交互仍待确认。后续重点是按[微信读书验证记录](../WEREAD_IMPLEMENTATION_TODO.md)完成设备闭环，不将旧移植清单重新列为未实现。云端进度同步和全书下载目前不属于应用能力。

## 保留的候选业务

| 候选方向 | 可复用基础 | 尚需明确的业务边界 |
| --- | --- | --- |
| 稍后读与 RSS/Atom | 公共 HTTPS、安装卷存储、共享阅读。 | 收藏来源、正文提取位置、摘要与全文区分、下载状态和离线缓存。复杂网页可由服务端整理，设备不需要完整浏览器。 |
| 日程、待办与课程表 | 本地记录、校时和静态页面。 | 本地任务、日历文件导入及订阅的关系，时区和全天事件；读取订阅不等于双向编辑同步。 |
| 阅读摘录与知识卡片 | 稳定阅读位置、文本和本地存储。 | 摘录随正文修订后的定位、笔记保存及导出，以及摘录文本和词条的传递约定。 |
| 无线书库 | 统一网络、下载文件和本地阅读。 | 远端目录、下载完成标识、同名文件及空间不足；只下载当前阅读器支持的内容。 |
| 智能家居状态与操作 | HTTPS、可见状态快照和输入。 | 目标服务的实际可达性、鉴别及操作反馈；PAN 能上网不保证能访问家庭局域网。 |
| 离线益智游戏 | 动态应用、触摸和持久化。 | 游戏逻辑与显示适配、棋局保存及恢复，按具体应用评估资源。 |

这些方向是业务储备，尚不构成安装包、发布支持或实施工期。选定后再明确应用身份、数据格式、服务依赖及验证入口。PM、语音、Wi-Fi 和 OTA 分别由本目录的专项文档维护。

## 已取消边界

图片只使用 16 灰阶，不保留普通灰阶或抖动模式切换目标。应用内存归属追踪及扩展统计体系已取消；对象的持有与释放关系继续作为并发和生命周期事实记录，不据此恢复该统计功能。现有技术储备保留可用机制，不以候选项数量代替当前产品能力。
