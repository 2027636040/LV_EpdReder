详细设计见 [SD 卡组件实施设计](C:/Users/xiebo/Documents/Codex/2026-09-22/bang/SD_CARD_COMPONENT_IMPLEMENTATION_DESIGN_20261005.md)。包定义和使用入口见 [组件说明](../components/sdcard/README.md)。

UI 通过组件变化版本继续调用既有目录刷新和安装恢复入口；后台安装恢复仍由原服务执行。退出确认改为携带已处理的请求号，同一请求成功确认后不再重复确认。这个签名调整仅涉及平台内部握手函数，不改变导出给动态应用的存储接口。应用目录、数据和缓存实现没有改动。

### 退出审计与修正

现有模块引用和取消机制继续使用，不新增另一套应用生命周期管理。确认退出的条件仍为：app_fwk 中没有动态应用页面、没有动态后台服务、没有存活模块引用，并且安装及恢复任务已经结束。组件收到对应请求号后，还会检查开放文件，随后才卸载文件系统和移除块设备。

| 持有者 | 源码核查结果 |
| --- | --- |
| 运行中的应用 | `app_module.c` 固定卷和会话。`storage_file.c` 在存在绑定时只验证原会话，失败后不重新搜索内部同名应用。 |
| 后台服务与串口命令 | `app_service.c` 持有模块引用；worker 返回后等待串口调用归零，解除网络订阅，再发布结束状态。UI 清理也完成后才关闭模块引用。 |
| 书架和 MOBI | 页面退出解除阅读显示引用；服务先等 worker 返回及页面销毁，再清理文档、关闭文件和解码库，最后释放阅读及书架服务资源。 |
| 天气、图库和单词 | 页面暂停时停用定时器，销毁时删除定时器；结果通过服务数据交接，后台不保存页面控件。图库等待绘图完成后释放显示像素；服务保留模块至请求和文件清理结束。 |
| 网络通知 | 网络服务只发送 RTOS 事件；发送和退订使用同一互斥锁，退订完成后才可销毁事件对象。 |
| 安装及事务恢复 | 安装前退出使用者，worker 持有共享 I/O 锁处理文件；平台等待任务结束，不在持有 I/O 锁时等待 UI 退出。 |

本项修正了三处项目侧边界，没有新增 SDK 修改：

1. 安装恢复结果增加所属卡会话；旧卡的 `recovery_ready` 不再被新会话沿用。
2. 退出超过提示时限后，即使内置 UI 恢复处理输入，安装入口仍检查未完成的退出请求，不启动新安装或卸载任务。
3. 插卡应用扫描在加锁后及扫描完成后核对原会话；扫描中移除卡时，不创建旧卡的加载提示。

主机测试执行 `python -B tools/tests/run_app_storage_tests.py`。服务和插卡提示测试使用移除 include 后的完整生产源文件；握手、恢复入口和路径选择测试逐字提取生产函数。替身模拟 RTOS、LVGL、文件系统及模块引用，覆盖规定的调度交错，不代表实机线程并发、驱动或 FAT 异常已通过。

消费者锁文件为 `project/.sf-pkg/conan.lock`，由 Conan 原生命令生成；仅该文件纳入版本管理，消费者 Python 文件、安装指纹和部署目录继续忽略。Conan 自动读取消费者文件旁的锁文件，已通过临时工程中的真实 `sdk.py sf-pkg install` 验证，不修改 SDK 或新增安装器。

锁文件固定组件与 Python 基础包的 recipe revision。Conan 0.5 锁文件不固定二进制包 revision；本次实际解析的包 ID/revision 见验证记录。两次离线解析结果一致，32 个部署源文件与组件源目录逐文件 SHA-256 一致；未将 Conan 自动生成的 `conaninfo.txt`、`conanmanifest.txt` 当作组件源文件。

从源码建立本地依赖的命令为：先激活 SDK 环境，在 `components/sdcard` 执行 `conan create . --version=1.0.0 --no-remote --lockfile=conan.lock`，再在 `project` 执行 `sdk.py sf-pkg install`。首次运行需已有锁定的官方基础包、SDK 的 Conan 扩展及默认 profile；缺包时先取得对应依赖，不删锁文件绕过。组件源码有意变更时，须重新创建包、更新清单 revision，再用原生 `conan lock create .sf-pkg/conanfile.py --no-remote --lockfile="" --lockfile-out=.sf-pkg/conan.lock` 重新锁定并审查结果。

`python -B tools/tests/validate_sdcard_package.py` 验证实际 SDK 安装入口、锁文件、重复解析、`--no-remote` 部署和隔离空缓存缺包失败。测试临时工程和缓存自动清理，不删除用户 Conan 缓存。板级离线构建使用已部署的依赖并设置 `SIFLI_SF_PKG_OFFLINE=1`；这个变量表示跳过自动安装，不应把它解释为检查或修复所有过期部署的机制。
