# 平台建设实施清单

## 实施范围

本清单覆盖平台公共能力、应用开发工具、参考组合和文档体系。低功耗、离线 OTA、语音输入及 Wi-Fi 驱动继续列入技术储备，不改变现有显示波形、供电时序和阅读调度。

## 任务与验收

| 编号 | 工作项 | 验收条件 | 状态 |
| --- | --- | --- | --- |
| P01 | 独立应用开发包 | 从已构建平台导出开发包；在仓库外编译应用、校验导入符号并生成可安装包 | 完成；两板各三个示例在工程外构建与打包通过 |
| P02 | 恢复启动 | 能持久设置禁止动态模块执行，保留内置管理入口，并能恢复正常启动 | 完成实现和主机测试；DPI 强制恢复固件编译通过，待板测 |
| P03 | 公共图片依赖 | 图库、阅读共用的解码依赖归入公共组件；现有调用方式不变 | 完成；依赖、图片及打包回归通过 |
| P04 | SD 组件发布准备 | 本地包、依赖、注册资料可检查；正式发布使用可验证的仓库和命名空间 | 本地材料和测试完成；正式发布待办 |
| P05 | 内容交接 | 文件管理器通过安装清单发现处理应用；支持文件路径传递和已运行应用接收 | 完成；书架和图库接入，四组地址检测测试通过，待板测 |
| P06 | 信息摘要与参考看板 | 公共接口按快照提供摘要；配置驱动参考页面；内容变化才更新控件 | 完成；摘要副本与配置测试通过，待板测 |
| P07 | 桌面预览 | 桌面与设备复用参考页面布局代码，提供可复现的预览入口 | 完成；同源几何、配置覆盖及分配失败测试通过 |
| P08 | 发布与参考组合 | 从安装包生成兼容性目录；校验包的固件身份；提供可复用构建组合 | 完成；两板各六个应用包通过校验并生成发布目录 |
| P09 | 平台文档 | 架构、演进、开发、部署、故障定位与技术储备都有明确入口和状态 | 完成；统一入口和本地链接检查通过 |
| P10 | 应用设计文档 | 每个动态应用说明职责、页面、数据、并发、生命周期、接口与验证方法 | 完成；六个应用及 hello 示例均有设计文档 |
| P11 | 集成验证 | 主机测试、独立应用构建、当前两种板型构建通过；更新对应安装包目录 | 两板普通固件、全部六个应用及天气/书架预装镜像构建通过；待板测 |

## 验证记录规则

主机测试、目标编译和设备运行验证分别记录。编译成功只证明构建闭合；热插拔、页面恢复、恢复启动和显示效果须通过上板检查。外部组件发布和社区服务部署须单独记录真实地址及结果。

具体命令、产物和设备检查表见[验收记录](PLATFORM_VALIDATION.md)。
