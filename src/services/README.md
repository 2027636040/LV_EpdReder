# 平台服务

公共服务面向主界面、内置页面和动态应用，业务应用不在此目录维护自身的天气、图书或词条逻辑。

## 服务边界

| 接口 | 职责 | 执行约定 |
| --- | --- | --- |
| `storage.h` | 挂载状态、卷变更、介质会话与短时 I/O 锁 | 在锁内检查路径可用性；不持锁等待 UI |
| `storage_file.h` | 安装位置路径、数据记录、文件替换 | 程序、数据和缓存使用同一应用的安装卷 |
| `app_service.h` | 受管工作线程、UI 分步工作、停止与模块引用 | 工作线程不能访问页面控件；停止需要协作完成 |
| `net/network.h` | 可用网络快照、多订阅者、路由与 DNS | 应用等待网络事件，不依赖蓝牙私有状态 |
| `net/network_time.h` | 网络就绪后的 NTP 校时 | 独立线程更新 RTC，不操作 LVGL |
| `net/bt_pan.h` | 蓝牙 PAN 开关、配对和连接 | 平台适配及设置使用；普通联网业务使用 network |

## 数据发布

后台线程将结果写入受保护的业务快照，页面在 UI 线程消费。简单信息可以使用
`epd_service_publish_summary()` 发布固件保存的文字副本。读取方通过
`epd_app_summary_revision()` 和 `epd_app_summary_read()` 检查变化，
不会调用发布应用的函数，也不会持有模块内数据地址。

服务停止后摘要不可读取。卸载必须等待工作线程、在途命令和页面清理结束；
不能仅删除页面就释放服务仍在执行的模块。

## 网络与时间

手机开启蓝牙网络共享并与设备配对后，PAN 适配器注册网卡。
应用在所选网络可用后发起请求；配置切换或断开使旧网络结果失效。
当前 NTP 默认服务器是 `ntp.aliyun.com`，时区为 UTC+8。
校时失败保留原 RTC 时间；重连后允许重新同步。

Wi-Fi 使用统一的网卡和 DNS 注册接口，具体硬件驱动尚未接入。
平台网络服务不包含天气同步频率、城市或在线书架业务。

## 应用私有服务

- [天气](../../modules/weather/DESIGN.md)：配置、城市历史、HTTP 请求、解析和缓存。
- [书架](../../modules/books/DESIGN.md)：TXT/MD/EPUB/MOBI 的扫描、准备、排版、位置和缓存。
- [图库](../../modules/gallery/DESIGN.md)：图片请求、解码和显示结果。
- [单词](../../modules/words/DESIGN.md)：词条读取、学习调度和学习记录。
- [微信读书](../../modules/weread/DESIGN.md)：登录、书架、章节与阅读会话。

`service_cmd.c` 的 `svc` 命令负责公共 PAN 命令和应用命令转发。
应用命令只有在对应受管服务运行且未停止时才执行；调用期间保持模块引用。
具体可用子命令以 `svc` 帮助及各应用说明为准。

服务和应用停止的详细顺序见 [生命周期约定](../../docs/APPLICATION_LIFECYCLE.md)。
