# UI 层（ui）

本层使用 LVGL v9 实现 Launcher、页面导航和状态显示，通过服务接口获取业务数据。

## 页面与交互

- 内置主界面、锁屏、书架、TXT 阅读、文件管理、分类设置和文本设置；
  天气及城市设置已迁入 `modules/weather`，仅安装完整天气包后提供入口。
  相册和文件传输不再保留入口或页面；WiFi 配网归入“设置 → 无线和网络”，当前未接入 WiFi 硬件驱动。
- KEY1 上选、KEY2 确认、KEY3 下选，长按 KEY1 返回；支持触摸输入。
- 刷新期间继续记录物理按键，屏幕空闲后将连续方向操作合并为最终焦点或目标页，
  只更新一次，不绘制中间选项或书页。首末页按输入顺序限制目标，菜单焦点循环选择。
  确认与返回各自保留顺序，分隔前后的方向操作。按键队列最多保存 32 段操作，
  同方向连按以计数保存；队列满时保留已有操作并打印新输入被拒绝的提示。
- 页面不显示底部按键提示；除主界面和锁屏外，统一使用标题行左侧的返回图标返回上一页。
  锁屏标题为 `SiFli EPD DEMO`，不显示电量，按 KEY2 或触摸小 KEY2 图标解锁。
- 页面切换即时完成，不使用动画、渐变、阴影或滚动惯性。
- 主界面每页两列四行，左右滑动切换应用页；多页时在快捷信息上方显示分页圆点。
  主界面不显示标题和锁屏按钮，快捷信息卡片保持 620×224 并贴齐屏幕底部，
  仅显示最近阅读和天气，正文使用 28 px、标题使用 36 px 字体。
- 状态栏日期时间和电量百分比使用 28 px 字体，电量未知时按 0% 显示。
- 天气页面包含当前天气、8 项详情、三天预报和来源区域信息；
  纵向布局均匀分配各区块间距，底部“更新”触发异步同步，顶部图标返回。
  天气设置支持 TF 配置导入、城市 ID 二维码和数字键盘校验，成功后持久化。
- 书架扫描当前文件系统根目录，每页显示 4 本 TXT 的大小、最近阅读、进度和已知页码；
  支持 UTF-8/GBK 正文，返回时恢复书架焦点。书架分页按钮在边界置灰并跳过焦点。
  无书籍时内容区仅显示“这里空空如也~”，不显示分页按钮或按键说明行。
- 阅读时 KEY1/KEY3 翻页、KEY2 返回，长按 KEY1 打开阅读设置；触摸正文左/右区域
  翻页，中间区域打开设置。面板支持暂存目标页、±1/±5 调整和确认跳转。
  阅读页保留紧凑的书名和返回栏，正文区域为 y=64 至 y=1151；底部保留细进度条，
  左侧显示电量，中间显示页码和进度，右侧显示 `HH:mm`。电量和时间随翻页及阅读菜单操作更新，
  定时状态采样不会单独触发阅读页刷新。
- 按 LVGL 实际字体度量分页，后台建立原文件字节偏移索引；计算过程中不触发刷新，
  完成后仅更新一次底栏总页数，不更新正文、进度条、电量或时间。
  阅读记录位于 `/flash/data/reader/`，分页缓存位于 `/flash/cache/reader/`；
  使用两份校验记录交替保存当前位置，并兼容读取 TF 卡上旧的 `.epd_reader/` 记录。
- 设置按显示设置、无线和网络、存储管理、应用管理、关于设备分类；
  文本设置页提供字体、字号、字重、行距、边距和编码选项。
  设置项修改后即时应用并保存，不再提供“保存设置”按钮。
- 字体、字号、字重、行距、边距、编码应用到阅读排版；从阅读菜单修改后，
  返回正文时按原文位置重新分页。合成粗体/细体在项目侧处理字形缓存并写回 PSRAM。
- 全刷周期应用到屏幕驱动，阅读菜单与通用设置共用同一周期；
  蓝牙开关接入 `btpan_enable()`，关闭时断开链路并停止重连，状态栏同步显示实际状态。
- 设置通过通用记录接口保存在内部 LittleFS，校验版本和 CRC，临时写入后同卷改名发布。
  默认网络接入统一网络服务；关机超时及低功耗状态机仍待后续实现，WiFi 控件尚无硬件驱动配合。
- 网络天气由独立工作线程处理，UI 只读取完整快照并更新变化字段；后台同步不弹窗。
  天气模块在后台发布平台持有的摘要副本，主页从服务管理器读取；主固件不引用天气私有类型或函数。
  手动同步弹窗不含动画，成功提示在屏幕显示完成一秒后关闭。其他预留业务和低功耗状态机尚未接入。

## 已有内容

- `ui_events.h`：按键/触摸动作（`UIAction`）与 `ActionCallback_t`，
  由 `src/boards/controls/buttons.c` 回调分发。
- `ui_app.c`：输入处理入口、状态采样和主线程界面更新。
- `platform/epd_input.c`：唯一的 LVGL 键盘设备、有序按键合并队列、页面/弹窗输入组及默认操作。
  控件组跟随 owner 对象释放，后台页面不接收输入；动态应用复用相同机制。
- `launcher.c`：内置页面生命周期、公共状态栏、弹窗、焦点恢复及锁屏输入语义。
- `apps/app_home.c`：Launcher 图标网格、应用列表分页和锁屏。
- `modules/books/`：可安装的书架/阅读应用，包含页面、TXT/GBK 引擎、分页和阅读记录。
- `apps/app_settings.c`：分类设置、文本设置、WiFi 配网入口和应用管理。
- `apps/app_files.c`：内部文件系统和 TF 卡目录浏览。
- `modules/weather/`：独立天气应用的页面、设置、业务、后台同步和资源选择。
- `apps/ui_pages.c`：现有页面的创建、恢复、暂停、销毁和动作接口组合。
- `platform/app_catalog.c`：枚举 SDK 内置应用和本地动态应用清单，向 app_fwk 注册装卸回调。
- `platform/epd_app.h` / `epd_app.c`：模块描述、平台字体/返回控件及额外 SDK/LVGL 符号导出。
- `ui_navigation.c`：现有页面 ID 到应用/子页路由的适配；导航栈及 screen 由框架管理。
- `ui_internal.h`：现有参考设计页面的私有控件上下文和内部接口，不是新增独立应用的依赖。
- `ui_font.c` / `ui_model.c`：Tiny TTF 字体及状态模型。
- 天气数据到文字、单位及图标代码的转换由 `modules/weather/ui_weather_data.c` 负责。
- `modules/books/ui_bookshelf_data.c`：真实书库快照与带校验的阅读记录。
- `modules/books/ui_reader.c`：分页、原文件偏移映射、索引缓存和断点续读。
- `ui_settings.c`：设置项、默认值和当前选择。
- `icons/`：公共 EZIP 图标声明；天气私有图库由 `tools/native_apps.py` 生成并随应用安装。
- `SConscript`：本目录、`icons/`、`apps/` 和 `platform/` 下的 `.c` 自动进入构建；
  `apps/` 的直接子目录可用自己的 `SConscript` 组织独立应用。

## 与数据服务层（services）的接口

| 能力 | 头文件 | 关键接口 |
|---|---|---|
| 应用摘要 | `app_service.h` | `app_service_summary()` 读取后台任务发布的副本，不调用模块代码 |
| 蓝牙 PAN | `bt_pan.h` | `btpan_get_state()` / `btpan_enable()` |
| 网络事件 | `network.h` | `network_snapshot()` / `network_subscribe()` / `network_unsubscribe()` |
| 阅读应用 | `platform/epd_app.h` | 字体、文本设置入口、状态与最近阅读摘要；书库和阅读引擎是模块私有接口 |

- 服务事件回调不可直接操作 LVGL 对象；通过消息队列或状态快照交给
  `ui_app_process()` 所在的主线程更新界面。

## app_fwk 页面生命周期

本项目使用 SDK `a25ebccd` 中的 LVGL V9 实现。应用注册、导航历史、
screen 创建和销毁统一交给 app_fwk；`ui_navigation.c` 只是项目页面 ID 到框架 API
的适配，不保存第二套导航栈。所有导航 API、生命周期回调和控件操作都在
`main` 的 LVGL 所在线程执行。

### 应用和页面划分

主界面注册为 `Main`，文件管理、设置为内置应用，书架/阅读和天气为可安装动态应用。
`GUI_MAX_RUNNING_APPS=2` 保留主界面与一个功能应用；应用内部的子页面数量不受这个值限制。
应用退出时由框架销毁其页面；列表起点、阅读位置、输入草稿等业务状态由功能模块显式保留。

| 应用 ID | 根页面 | 子页面 |
|---|---|---|
| `Main` | 主界面 | 锁屏 |
| `books`（动态） | 书架 | 阅读、复用平台的文本设置 |
| `settings` | 分类设置 | 显示、文本、无线和网络、WiFi 配网、存储、应用管理、关于设备、锁屏 |
| `files` | 内部存储/TF 入口 | 目录内容、锁屏 |
| `weather`（动态） | 天气或 Intent 指定的天气设置 | 城市二维码、城市输入 |

Launcher 枚举 SDK 的内置应用表及 `/flash/apps`、已挂载 TF 卡的 `/sdcard/.epd/apps` 中的动态应用清单，不再维护固定入口描述列表。内置描述符中提供图标的应用
会出现在网格中；主界面的图标为空，不显示自身入口。已安装的书架和天气、文件管理、设置优先，
其他应用按 ID 排在后面，每页八项，超过八项才显示分页圆点，左右滑动切换。
翻页复用图标卡片；首末页不循环，滑动释放不会触发应用点击，返回主页时保留所在页。
目录只保存显示信息，不保存应用运行状态或导航历史。
内置页面的锁屏可以由 UI 线程通过 `launcher_open(UI_PAGE_LOCK)` 覆盖当前功能页，
解锁只返回上一页，不重新打开主界面。原页面控件、焦点和输入内容保留。
阅读菜单与确认提示仍是所属页面内的控件，不注册成应用或导航页面。

- 阅读页返回书架时保留书架列表位置与选中项；阅读位置仍由原有字节偏移记录恢复。
- 阅读菜单进入文本设置，返回时恢复原菜单和焦点；改变排版参数才重新分页。
- 天气模块的城市输入成功后调用框架的“返回指定页面”，回到天气设置根页，
  销毁二维码和输入页；从天气设置返回系统设置。失败则保留输入内容。
- 页面销毁后的焦点索引、书架列表起点和未提交城市输入，另存为轻量 UI 状态；
  这些状态不保存页面顺序，不参与导航决策。城市设置成功后清除输入草稿。
- 打开已存在的页面使用“返回指定页面”，不调用会重建同名页面的旧式创建接口。

### 职责和对象所有权

| 回调 | 项目负责 | 框架负责 |
|---|---|---|
| ONSTART | 取得框架 screen，创建控件、焦点组，恢复轻量状态 | 创建 screen，分配并清零页面上下文 |
| ONRESUME | 标记前台，读取最新业务快照，按字段差异更新，恢复焦点 | 将页面 screen 切到前台 |
| ONPAUSE | 保存焦点、列表/输入状态和阅读位置，停止该页界面轮询 | 保留 screen、控件和页面上下文 |
| ONSTOP | 清理页面专属任务和异步结果票据，不手工删除受管焦点组 | 在回调后删除 screen 及其子控件，触发平台输入组释放，再释放页面上下文 |

普通前进的顺序是旧页 ONPAUSE、新页 ONSTART、新页 ONRESUME。
返回已有页面时，离开页先 ONPAUSE，目标页 ONRESUME，随后离开页 ONSTOP。
销毁回调可能发生在另一页已恢复之后，因此清理回调临时绑定自己的上下文，
不能清空新前台页的控件指针。

页面代码不创建顶层 screen，不自行加载或销毁框架 screen。
页面内弹窗关闭时可删除自有子控件；页面退出时未关闭的弹窗随 screen 一起销毁。
内置页面由主线程处理前台更新。天气模块使用页面私有 LVGL 定时器读取快照，
ONPAUSE 暂停、ONSTOP 删除，只更新变化控件；后台线程不持有控件指针。

### 调度和数据更新

app_fwk 用容量为 10 的邮箱排队导航消息，LVGL 定时器负责调度。
本配置 `LV_DEF_REFR_PERIOD=16`，框架调度周期为 32 ms，不等于屏幕重绘周期。
适配层在 UI 操作处理阶段发送一个导航请求，然后调用 `gui_app_exec_now()`
完成生命周期调度，并查询框架的实际前台页面确认结果，再消费后续按键；
生命周期回调不递归发起同步调度。页面打开失败时保留原页面并提示重试，
打开书籍时新建但尚未进入阅读页的会话会被释放，不写入新的阅读位置。
原按键队列、方向合并、确认/返回顺序边界和受控阅读目标保持不变。

- 天气、PAN、NTP 的独立线程和互斥保护不受页面生命周期影响。
  天气模块更新或卸载时，受管线程收到停止请求并退出，页面退出本身不会停止线程。
  天气票据只与发起操作的页面上下文关联；页面退出后服务仍可完成请求，
  结果通过快照读取，不回调已销毁控件。
- `books.so` 通过受管服务的 `ui_process` 在 UI 线程调用原有分步排版器，不另起线程并发访问 LVGL。
  退出页面保留服务引用；卸载、更新或存储释放时，等页面与在途命令退出后关闭文件、释放字体和缓存，再卸载模块。
  已开始的任务在离开阅读页后只继续建立分页索引，不执行待翻页或更新正文位置；
  退到后台时取消待翻页，保留离开时的阅读位置和未确认的菜单输入。
  阅读页销毁且计算完成或出错之后，
  才保存并释放阅读会话。锁屏或文本设置覆盖阅读页时保留会话。
  会话存续期间不重新扫描、替换它所引用的书架列表。
- 分页过程中不通知界面重绘；前台阅读页发现总页数首次完成时，只更新底栏。
  书架在恢复或分页收尾时更新原有卡片，翻列表页也不重建 screen。
- 阅读字号等变化时，先让正文控件脱离旧字体，再重排并绑定新字体，
  防止保留的阅读页继续引用已释放的字体。

### 本地 SDK 依据与配置

| 机制 | SDK 源码 |
|---|---|
| 内置应用描述及根页/子页接口 | `middleware/include/gui_app_fwk.h` |
| 导航、页面内存和生命周期公共接口 | `middleware/include/gui_app_fwk2.h` |
| 注册表选择、邮箱发送、初始化、同步调度 | `middleware/app_fwk/gui_app_fwk.c`：`send_msg_to_gui_app_task`、`gui_app_init`、`gui_app_exec_now` |
| 状态机、页面分配、返回目标页、screen 所有权 | `middleware/app_fwk/app_schedule.c`：`page_state_machine`、`app_create_page`、`app_goback_to_page`、`schedule_subpage` |
| LVGL V9 定时器和输入端口 | `middleware/app_fwk/app_schedule_port.c` |
| V9 目录选择及无动画实现 | `middleware/app_fwk/SConscript`、`lvgl_v9/gui_app_trans_anim.c` |
| V9 完整应用例程 | `example/multimedia/lvgl/watch_v9/src/gui_apps/watch_demo.c`、`rotation3d/rotation3d.c` |

“返回上一页”销毁当前页面并恢复前一页；“返回指定页面”销毁该目标之前的页面；
“退出应用”则停止整个应用的页面，由框架恢复其他应用或默认 Main。
普通 ONPAUSE 不释放控件；框架因运行应用数量限制而挂起应用时，会停止并销毁其页面，
后续重新运行入口。功能模块显式保存业务状态，不把跨应用保活作为持久化机制。

`EPD_USE_LVGL` 将 app_fwk 及兼容组件设为必选依赖，不提供独立的框架关闭选项。
项目配置启用 `APP_TRANS_ANIMATION_NONE`，并在链接脚本中保留
`.BuiltinApp1Tab`、`.BuiltinApp2Tab` 和 `.app_subpage_db` 注册段，匹配 SDK 的 GCC 注册宏。

固定 SDK 的 V9 `app_trans_animation_reset()` 在无动画配置下仍引用
`lv_switchanim_manual_finish()`，而组件默认未编译，实际链接会失败。
项目 Kconfig 因此选择现有 `LVSF_USING_SWITCHANIM` 和它要求的 `LV_USE_SNAPSHOT`，
只补足链接依赖；无动画分支的初始化为空、切换返回 `RT_EEMPTY`，不会创建转场对象
或分配转场截图。每页还调用 `gui_app_close_anim()` 关闭进入和退出效果。
导航适配没有新增 SDK 源码补丁，也未修改 SDK 指针。今后 SDK 修复这个条件编译缺口后，
可以移除这两个兼容依赖。

屏幕驱动、波形、扫描时序、缓存写回、未变化灰度不驱动、刷新后断电及全刷周期
均不由导航适配层重新实现。

### 上板检查

启动日志应出现 `page[Main][root] do ONSTART`、`page[Main][root] do ONRESUME` 和
`Launcher ready`，随后出现首次屏幕刷新。`Main/root did not enter the foreground`
表示框架启动未完成，不代表一定是内存不足。

1. 反复进入各入口并逐级返回，确认布局不变、焦点恢复，内存不持续增长。
2. 在书架非第一页打开书籍后返回，确认列表位置、选中书籍和进度正确。
3. 在阅读菜单中进入文本设置，修改字号后返回，确认原文位置、菜单焦点及总页数更新。
4. 在内置页面锁屏再解锁，确认原页面与焦点恢复；天气模块反复进入返回城市输入页，确认草稿与已提交城市正确。
5. 在主页等待 PAN 联网和天气同步；离开天气页后等待后台更新，再进入检查最新数据。
6. 连续按方向键，中间穿插确认/返回；确认只刷新最终选择且没有跨越顺序边界。
7. 大 TXT 分页过程中返回书架或锁屏，确认任务继续完成；阅读页留在前台时，
   总页数完成只触发一次底栏更新。
   请求尚未排出的目标页后立即返回书架，等待分页完成再打开书籍，确认仍恢复离开时的位置。
