# UI 层（ui）

本层使用 LVGL v9 实现 Launcher、页面导航和状态显示，通过服务接口获取业务数据。

## 页面与交互

- 主界面、锁屏、书架、TXT 阅读、天气、城市选择、设置和文本设置已实现；
  文件传输、相册、Wi-Fi 配网和关于设备保留页面入口及返回。
- KEY1 上选、KEY2 确认、KEY3 下选，长按 KEY1 返回；支持触摸输入。
- 页面切换即时完成，不使用动画、渐变、阴影或滚动惯性。
- 天气页面包含当前天气、8 项详情、三天预报、城市选择和更新提示；
  城市确认后切换本地初始数据，取消保留原城市。
- 书架扫描当前文件系统根目录，每页显示 4 本 TXT 的大小、最近阅读、进度和已知页码；
  支持 UTF-8/GBK 正文，返回时恢复书架焦点。书架分页按钮在边界置灰并跳过焦点。
- 阅读时 KEY1/KEY3 翻页、KEY2 返回，长按 KEY1 打开阅读设置；触摸正文左/右区域
  翻页，中间区域打开设置。面板支持暂存目标页、±1/±5 调整和确认跳转。
- 按 LVGL 实际字体度量分页，后台建立原文件字节偏移索引；计算总页数不会主动刷新。
  阅读记录与分页缓存位于 `/.epd_reader/`，使用两份校验记录交替保存当前位置。
- 设置页提供触控、蓝牙、Wi-Fi、低功耗开关，以及关机超时、全刷周期和默认网络选项；
  文本设置页提供字体、字号、字重、行距、边距和编码选项。
  触摸整行或按 KEY2 即时切换，选择仅保存在内存中，页面往返保留、重启恢复默认值。
- “保存设置”显示确认弹窗，“保存 ← 返回”和“确认返回”回到上一级；
  字体、字号、行距、边距、编码应用到阅读排版，全刷周期应用到屏幕驱动；
  字重、关机超时和无线/低功耗设置仍只保留控件，不执行硬件操作。
- 网络天气请求、其他子页面业务和低功耗状态机尚未接入。

## 已有内容

- `ui_events.h`：按键/触摸动作（`UIAction`）与 `ActionCallback_t`，
  由 `src/boards/controls/buttons.c` 回调分发。
- `ui_app.c`：按键消息队列、状态采样和主线程界面更新。
- `launcher.c`：页面对象、页面栈、焦点和墨水屏样式。
- `ui_font.c` / `ui_model.c`：Tiny TTF 字体及状态模型。
- `ui_weather_data.c`：天气页面的城市初始数据及和风天气代码。
- `ui_bookshelf_data.c`：真实书库快照与带校验的阅读记录。
- `ui_reader.c`：分页、原文件偏移映射、索引缓存和断点续读。
- `ui_settings.c`：设置项、默认值和当前选择。
- `icons/`：内置 A8 图标。
- `SConscript`：本目录和 `icons/` 下的 `.c` 自动进入构建；
  需要额外头文件路径时在自身 `SConscript` 中追加 `CPPPATH`。

## 与数据服务层（services）的接口

| 能力 | 头文件 | 关键接口 |
|---|---|---|
| 天气数据 | `weather.h` | `weather_request_refresh()` / `weather_get_info()` / `weather_set_event_cb()` / 城市接口 |
| 蓝牙 PAN | `bt_pan.h` | `btpan_get_state()` / `btpan_enable()` / `btpan_set_event_cb()` |
| 书库 | `bookshelf.h` | 扫描、列表和进度接口 |
| 阅读 | `reader.h` | 打开书籍、按偏移取文本和位置接口 |

- 详细用法与线程约定：见 `src/services/README.md`
- 服务事件回调不可直接操作 LVGL 对象；通过消息队列或状态快照交给
  `ui_app_process()` 所在的主线程更新界面。

## 构建

```powershell
. <SiFli-SDK>\export.ps1
cd project
scons --board=dpi-hdk_lb57gyd7n6_epd --board_search_path=.. -j8
```

屏幕规格：684 × 1216（竖屏）；墨水屏刷新模式与全刷周期控制见仓库根 `README.md`。
