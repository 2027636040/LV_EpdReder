# 单词应用设计

## 目的与内容模型

`words.so` 提供离线查词、完整词条、今日学习、生词本和学习范围设置。当前[清单](app.json)版本为 3、数据版本为 1，提供设置入口，不声明开机常驻后台。应用进入时启动服务，正常返回根页之前同步学习数据。

词条、学习范围和学习状态分别组织。ECDICT 与 kajweb/dict 的内容在电脑端合成为 WDB2 统一词库；设备按同一套索引查词和学习。范围是统一词库中的成员集合，同一单词属于多个范围时不复制正文，也不重复建立学习身份。格式定义见 [WDB2.md](WDB2.md)。

| 部分 | 职责与执行位置 |
| --- | --- |
| [words_pages.c](words_pages.c)、[words_ui.c](words_ui.c) | UI 线程中的首页、学习、查词、详情、生词本及范围设置页面。 |
| [words_service.c](words_service.c) | 单个受管工作线程，串行查词、选卡、评分、收藏、范围切换及保存。 |
| [words_store.c](words_store.c) | 配置、学习记录块、内容快照和内存索引；服务线程是业务数据写入者。 |
| [words_dictionary.c](core/words_dictionary.c)、[words_content.c](core/words_content.c) | 通过随机读取接口访问词库并解析单条内容，不依赖整库常驻内存。 |
| [words_fsrs.c](core/words_fsrs.c)、[words_learning.c](core/words_learning.c) | 根据记忆状态安排下次复习的 FSRS-6 算法，以及卡片选择、统计逻辑。 |
| [build_dictionary.py](tools/build_dictionary.py) | 电脑端合并、规范化、生成成员索引和来源报告；设备不解析原始 CSV/JSON。 |

## 设计意图与取舍

用户面对一个统一词库和可选择的学习范围，不面对数据来源或文件选择。电脑端完成 ECDICT 与 kajweb 的清理、关联、去重和索引，设备只随机读取当前条目；这样把重复的数据准备移出设备首次使用和正常编译，代价是内容更新必须重新生成并部署 WDB2，不能直接复制原始 CSV/JSON 使用。

同一原始词头的来源内容互补，保留释义、音标、例句、短语及来源关系；仅合并可靠判同的内容，不靠拼接或推测将不同词义的例句配在一起。以完整单词作为学习卡片，不按词义拆卡。查询的大小写折叠和词形定位只提高查找便利性，不据此改写稳定学习身份。

范围决定后续新词成员，已学单词和到期复习属于统一学习记录。因此切换范围不会清空学习状态，也不会把重叠词重新视为新词。FSRS-6 和四档评分继续复用，不以词库升级为由重新设计记忆算法；旧配置、词库和记录的迁移规则必须保留内容身份。

标准包携带完整词库，选择 TF 卡承担容量，不静默改成小词库或依赖在线下载。资源输入进入 Git，生成报告记录真实来源和摘要；这意味着更大的仓库、安装包及安装耗时。查词按需读取，不意味着安装阶段不需复制和校验完整文件。

后台有序保存评分、收藏和配置，正常退出完成必要同步；突然断电可丢失尚未保存操作，但不能错误恢复半写记录。范围组合、词频排序、Qwerty Learner 适配和在线词典均不是此次统一词库的附带目标。平台层取舍见[开发意图与设计决策](../../docs/DESIGN_INTENT.md)。

## 查词和学习流程

查词按完整词头、词形映射、前缀候选的顺序查找，一次最多显示八个候选。查询键只折叠 ASCII 大小写；学习身份保留原始大小写，以 `en:<NFC 原始词头>` 表达，`Apple` 与 `apple` 不自动合并。屈折词形用于找到词条，同根词则作为内容显示。

打开详情后分别展示音标、释义、词形、例句、短语、同根词、范围和来源。相同原始词头关联为一条记录；只有规范化后完全相同的同类内容才合并，不覆盖不同来源的释义。ECDICT 的中英文释义没有可靠的一一关系，不能强行配对。

学习流程为“取得未评分卡片或下一张卡 → 查看答案 → 四档评分 → 更新记忆状态 → 保存”。已有未评分会话优先恢复；随后安排到期的学习/重学、到期复习和新词。默认每天 20 个新词，设置范围为 0～200，到期复习不受新词额度限制。范围新词与未学习收藏词按现有配额规则共同进入新词队列。

FSRS-6 使用默认 21 参数、90% 目标回忆率、60/600 秒学习步骤、600 秒重学步骤和最长 36,500 天间隔，关闭随机微调。服务将平台时间转换为调度使用的 UTC 秒；时间无效时仍可查词，但学习入口和评分返回需要设置时间的结果。

评分请求携带记录槽号及当前卡片令牌 `token`，服务核对后才接受，防止旧页面重复评分。切换学习范围只改变后续新词来源及游标，保留已学状态、旧范围到期复习、收藏、暂停状态和未评分会话。移出生词本不删除已有学习记录。

## 生命周期与数据所有权

`app_main()` 根据 `page=settings` 决定以设置页或首页为根页。根页 `ONSTART` 创建控件并调用 `words_service_start()`；`ONRESUME` 提交当前页数据请求；`ONPAUSE` 暂停定时器并使本页请求代次失效；`ONSTOP` 删除定时器、释放结果，根页再请求服务停止。screen 和页面内存由 app_fwk 管理。

[words_service.h](words_service.h) 中的 `words_submit()` 复制请求并返回 `serial`；队列当前最多保存八项，不能入队时返回 0。搜索、详情、范围读取和选择任务可以在过期时取消。已经接受的评分、收藏等修改按队列顺序处理，不因页面暂停而当作只读请求丢弃；完整服务停止和突然拔卡仍可能中断未完成操作。

服务返回独立的 `words_result_t`。`words_take()` 将匹配编号的结果交给 UI，页面负责调用 `words_result_free()`。词条字段借用结果自身的内容缓冲，不能比结果活得更久；详情排版文本及页起点由详情页持有。后台不保存控件指针，不在 UI 线程做词库读取或持久化。

词库文件句柄只在当前任务内打开和关闭。结果携带词库身份信息，进入详情或使用成员序号前重新核对，防止旧序号引用新词库。词库更新后，学习记录仍按原始词头关联，不以文件偏移或临时索引作为永久身份。

## 持久化与词库选择

内部安装的数据目录为 `/flash/data/words`，TF 卡安装为 `/sdcard/.epd/data/words`。

| 文件 | 内容与提交方式 |
| --- | --- |
| `config.dat` | 学习范围、词库身份、新词游标、每日额度和未评分会话；应用配置格式为 2，可迁移旧格式 1。 |
| `states/000.dat` 等 | 每块 32 条学习记录，使用平台版本及 CRC 记录接口。 |
| `content.bin` | 已学习和收藏词的内容快照，按长度与偏移访问；独立于外部词库的索引顺序。 |
| `library.wdb` | 可选的完整统一词库替换文件。 |

服务按以下优先级选择一个统一词库：

1. 应用数据目录的 `library.wdb`。
2. `/sdcard/words/library.wdb`。
3. 应用安装目录的 `res/library.wdb`。

缺失文件可继续查找下一个位置；找到但格式损坏的高优先级词库会报告错误，不静默切换。替换文件代表完整统一词库，不是供用户选择的第二套词书。旧 `book.wdb` 和 `books/` 不再作为入口，旧 WDB1 读取仅保留兼容。WDB2 生成、迁移及部署细节见[应用说明](README.md)。

服务先发布评分结果，再顺序保存；结果中的“已接受”不等于写盘完成。根页返回调用 `words_service_flush()`，保存失败时停留并提示重试。词库替换在应用退出后进行，重新进入才读取新身份与索引。TF 卡移除会统一停止动态应用，内部安装但读取卡内替换词库的单词应用也参与退出；重新插卡需确认加载。突发掉电或拔卡可能丢失尚未落盘的数据。

## 构建与安装位置

```powershell
. .\SiFli-SDK\export.ps1
scons -C project --board=dpi-hdk_lb57gyd7n6_epd_hcpu -j8
scons -C modules APPS=words -j8
```

命令在仓库根目录执行；已有兼容平台时只构建应用。单词打包另外需要 Node.js 和 `sharp`。默认读取 `modules/words/assets/dictionary/library.wdb.gz` 及来源报告，在电脑端解压并校验后打包，不下载原始词库或在设备首次启动时生成索引。

标准输出为 `project/build_dpi-hdk_lb57gyd7n6_epd_hcpu/app-resources/words/`，包含模块、图标、`res/library.wdb`、报告与许可证。完整统一词库为 213,991,764 字节，约 204.08 MiB，不能装入约 5.48 MiB 的内部文件系统；标准完整包安装到 TF 卡的 `.epd/apps/words`，数据随卡保存。来源包放在 `apps/words`，与安装后的运行目录分开，需要同时容纳来源包和安装副本。

TF 卡内原位更新保留学习数据。从内部存储迁移时先通过系统卸载，再选择 TF 卡安装；当目标没有同名数据且另一卷只遗留该应用数据时，平台复制、校验后迁移。目标已有数据时不会自动合并两份学习记录。更高优先级的旧替换词库仍会遮蔽随包新库，部署时应一并核对。

LCD 载板、裁剪词库覆盖参数及预装规则见[构建说明](../../docs/BUILDING.md)。词库来源及再分发条件见[应用说明的资源来源](README.md#资源来源与授权)，统一文件格式不改变原始内容的授权范围。

## 验证入口与演进

[test_core.py](tests/test_core.py) 检查读取器与调度核心，[test_unified.py](tests/test_unified.py) 检查 WDB2 内容及成员索引，[test_learning.py](tests/test_learning.py) 检查学习、保存与迁移；宿主库构建命令见[应用说明](README.md#测试)。设备验证关注查词与学习使用同一内容、跨范围复习、未评分恢复、保存失败提示及 TF 卡移除。

早期分散词书导入方案已由 WDB2 统一词库替代。语音输入仍是[平台技术储备](../../docs/reserves/SPEECH_INPUT.md)，没有接入当前单词页面。
