# WDB2 文件格式

所有整数为无符号小端，文本为 NFC UTF-8，字符串以 NUL 结束。文件最大长度受设备有符号 32 位文件偏移限制。词头键为 ASCII 小写索引，永久学习身份为 `en:` 加 NFC 原始词头（区分大小写）。词形映射只影响查询，不改变身份。

## 文件布局

文件依次包含 96 字节头、词头索引、词形索引、范围表、范围成员、词条正文、来源 JSON 元数据。

| 头偏移 | 字段 |
| --- | --- |
| 0 | 8 字节 `EPDWD02\0` |
| 8 | version=2 |
| 12,16 | 词条数、词形索引数 |
| 20,24,28 | 词头索引、词形索引、正文的绝对偏移 |
| 32,36 | 文件总字节数、key_size=96 |
| 40 | 24 字节 generation：头后全部内容 SHA256 的前 24 字节 |
| 64,68,72 | 范围数、范围表偏移、成员区偏移 |
| 76,80 | 元数据偏移、元数据长度 |
| 84..95 | 保留，必须为零 |

词头索引每项 104 字节：`key[96], offset:u32, length:u32`，按 `(ASCII小写词头, 原始词头)` 排序。词形索引每项 100 字节：`key[96], entry:u32`，排序并去重。

范围表每项 104 字节：`id[32], name[64], first:u32, count:u32`。first 是成员区内的 u32 序号。成员为词头索引序号，逐范围升序且去重。范围 ID 是稳定 ASCII 标识，例如 cet4；名称供界面展示。范围定义和来源映射保存在生成报告。范围重叠不复制词条正文。

## 词条正文

`00 45 4e 32` 四字节标记、`record_count:u32`、原始词头 NUL 字符串，随后为 record_count 个记录。首字节为零，与旧快照的非空词头明确区分。每个记录为 `type:u32, bytes:u32, payload[bytes]`；payload 是下表指定数量的 NUL 字符串，必须恰好消费记录长度。

| type | 内容 | 字符串顺序 |
| --- | --- | --- |
| 1 | 音标 | 变体（general/uk/us）、音标、来源集合 |
| 2 | 释义 | 词性、中文、英文、来源集合 |
| 3 | 词形 | 类型、词形、来源集合 |
| 4 | 例句 | 英文、中文、来源集合 |
| 5 | 短语 | 英文、中文、来源集合 |
| 6 | 来源关联 | 来源 ID、原始记录 ID |
| 7 | 学习范围 | 范围 ID、显示名、来源集合 |
| 8 | 同根词 | 词性、词头、释义、来源集合 |

来源集合采用逗号分隔的来源 ID，ID 不含逗号。ECDICT ID 为 ecdict；kajweb ID 为 kajweb:文件内 bookId，版本和文件摘要在元数据中。记录去重按类型及正文文本进行，重复内容合并来源集合。不同音标、释义或译文保留为不同记录，不覆盖。ECDICT 中英文释义没有可靠一一对应关系，分别保留；kajweb trans 中同一对象的中英文组成一个释义记录。例句和短语归词条，不推断词义关系。同根词不作为屈折词形查询别名。

## 兼容与读取

WDB1 保持可读，其六字段快照不改写为其他单词。WDB2 正文以标记区分旧快照。学习记录块结构不变；内容按字节长度及 CRC 保存，更新内容不改变 FSRS 状态。配置升级保留额度和 pending，范围游标在文件 generation 或范围改变后复位。

读取器检查各段连续性、索引范围、记录长度、字符串终止和文件实际读取结果。不按固定词条字节数拒绝内容；分配失败由应用返回错误。单次任务持有文件，结果只持有内容快照；任务结束关闭文件。查询结果携带 generation，打开详情时再次检查，避免旧索引指向新词库。
